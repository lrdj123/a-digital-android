# 🖐️ A DIGITAL — App Android P2P

    App de segurança financeira entre dispositivos **sem servidor central**.

    ## ✨ Telas

    | Tela | Descrição |
    |---|---|
    | Splash | Logo animado + inicialização |
    | Login / Cadastro | Firebase Auth (email + senha) |
    | Dashboard | Cards das funcionalidades |
    | Transação P2P | Biometria + análise emocional + criptografia E2E |
    | SOS Invisível | Cadastro de contatos de confiança + histórico de alertas |
    | Histórico | Lista de transações com hash e status |

    ## 🚀 Como abrir

    1. Clone o repositório
    2. Abra no **Android Studio**
    3. Adicione seu `google-services.json` em `app/`
    4. Compile e instale no celular

    ## 📦 Dependências principais

    - Firebase Auth + Firestore + FCM
    - Android Biometric API (impressão digital)
    - Material Design 3
    - CameraX (análise facial futura)

    ## 🔧 Configuração

    No Firebase Console:
    1. Crie projeto → adicione app Android (`com.adigital.p2p`)
    2. Baixe `google-services.json` e coloque em `app/`
    3. Habilite Auth (email/senha) e Firestore
